
# Week 4 - Supplier Tender Evaluation

## Description
This program evaluates suppliers who submit requests to join the municipality. It determines whether a supplier is Qualified or Disqualified based on three criteria:
1. The supplier is registered.
2. All required documents are complete.
3. The supplier price is within the company budget.

## How to Compile and Run
gcc supplier.c -o supplier
.\supplier.exe
